# CodeAlpha_Basic-Network-PacketSniffer

A simple packet sniffer built in Python using Scapy for the CodeAlpha internship.

## How to Run
1. Install Scapy: pip install scapy
2. On Windows, install Npcap and enable WinPcap API-compatible Mode
3. Run as Administrator: python python sniffer.py
4. Press Ctrl+C to stop. It saves packets to capture.pcap
